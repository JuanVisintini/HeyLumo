# 06 - Data Model

# Business Profile

## Overview

The Business Profile is the central domain object of the platform.

Every generated asset starts from this object.

The Business Profile is provider-independent.

It does not represent Instagram, Google Business or Facebook.

It represents the business itself.

Every connector transforms external information into this unified model.

---

# Principles

## Single Source of Truth

Every system component reads from the Business Profile.

No component should consume external providers directly.

---

## Provider Agnostic

The model should never expose provider-specific fields.

Bad

```json
{
    "instagramFollowers": 1200
}
```

Good

```json
{
    "socialProfiles": []
}
```

---

## Structured First

Avoid large text blobs.

Prefer structured information.

Bad

```json
{
    "description": "Open Monday to Friday..."
}
```

Good

```json
{
    "openingHours": []
}
```
